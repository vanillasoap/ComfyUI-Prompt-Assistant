OBJECTIVE
---------
Translate the ComfyUI-Prompt-Assistant codebase from Chinese to English,
ensuring nothing breaks and future merges with the main repository remain
possible. Scope was later narrowed to frontend files only (JS + JSON).

APPROACH
--------
- Used phrase-level translation dictionaries applied via Python scripts for
  bulk replacements (word-level was tried first but produced garbled text).
- Parallel background agents were used for initial bulk translation across
  many files simultaneously.
- Work was committed incrementally in 6 batches to maintain safe checkpoints.
- Chinese service detection patterns (e.g. '智谱', '硅基') in
  apiConfigManager.js were kept as-is since they are matching patterns, not
  display strings.
- Backward-compatible alternatives were added where needed (e.g. adding
  English name checks alongside Chinese ones in .find() calls).

NOTABLE DECISIONS
-----------------
- '用户标签.csv' was renamed to 'user_tags.csv' in JS resourceManager.js
  (referenced in both Python config_manager.py and JS).
- Chinese service detection patterns ('智谱', '硅基') in apiConfigManager.js
  were preserved since they are used for API provider identification, not UI.
- In captionFrame.js, backward-compatible checks were added:
  i.name === "Video" || i.type === "VIDEO" (alongside existing Chinese check).
- The locales/ directory (locales/en/nodeDefs.json, locales/zh/, locales/zh-TW/)
  was left untouched as it is part of the existing i18n system.

ERRORS AND REVERSIONS
---------------------
- Word-level dictionary translation attempt produced garbled Chinglish output
  (e.g. "IfinsertedFormatDoes not exist或未找到"). Files were reverted with
  git checkout and phrase-level approach was used instead.
- Duplicate condition created in captionFrame.js when both manual edit and
  script translated the same string; fixed by deduplication.
